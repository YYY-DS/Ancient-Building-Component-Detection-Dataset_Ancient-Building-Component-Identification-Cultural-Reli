## 数据集概述

本数据集专注于**古建筑构件与装饰元素的视觉检测与分类**，服务于古建筑保护、文物普查及建筑遗产数字化。数据涵盖13类典型古建筑构件，适配无人机巡检、建筑遗产普查及自动化构件识别等应用。

## 数据三要素解析

**类别与构件覆盖**
*   数据集定义 **13** 类古建筑构件，覆盖 **结构构件**（椽子、飞椽、额枋、雀替、台基、须弥座）、**屋面构件**（琉璃瓦、筒瓦、瓦当、滴水）、**装饰构件**（抱鼓石、栏杆）及 **其他**（玉露）。
*   类别设置覆盖了中国传统建筑的主要构件类型，具有较强的专业性与系统性。
*   类别以拼音标注，使用前建议先核对 `data.yaml` 确认具体含义。

**数据规模与版本**
*   图像总量约 **1698** 张，规模适中，能支撑多类别构件检测模型的训练。
*   数据集有 **4** 个版本，可能包含不同标注完善度或数据增强的迭代版本。
*   图像涵盖古建筑不同部位与不同光照条件下的构件样本。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，便于进行训练/验证集划分与预处理集成。

## 知识普及：古建筑构件检测的技术要点

*   **构件形态多样**：从细长的椽子到复杂的须弥座，构件在形态、尺度上差异显著，需模型具备多类别特征提取能力。
*   **材质与纹理干扰**：古建筑构件材质（木材、砖石、琉璃）纹理复杂，可能与构件混淆，模型需依赖纹理与颜色特征进行区分。
*   **密集与遮挡**：古建筑构件密集排列，相互遮挡常见，需采用多尺度特征融合与NMS参数调优策略。
*   **光照与视角影响**：古建筑多为户外拍摄，光照变化大，且拍摄角度多样，建议训练时加入亮度、对比度增强与视角变换。
*   **应用闭环**：检测结果可导入古建筑BIM系统，用于构件编目、状态评估与修缮规划，服务于建筑遗产的数字化保护。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例（需根据实际类别含义填写）：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 13
names: ['baogushi', 'chuanzi', 'dishui', 'efang', 'feichuan', 'langan', 
        'liuliwa', 'queti', 'taiji', 'tongwa', 'wadang', 'xvmizuo', 'yulu']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
