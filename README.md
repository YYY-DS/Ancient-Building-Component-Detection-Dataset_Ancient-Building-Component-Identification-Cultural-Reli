## 数据三要素解析

**类别与构件覆盖**
*   数据集定义 **19** 类古建筑构件，覆盖 **屋顶构件**（博风板、垂脊、飞檐、戗脊、正脊）、**斗拱体系**（斗拱、补间铺作、转角铺作、柱头铺作）、**支撑构件**（梁架、牛腿、驼峰、月梁、柱础、柱子）及 **装饰构件**（悬鱼）。
*   类别设置覆盖了中国传统建筑的主要构件类型，具有较强的专业性与系统性。

**数据规模与版本**
*   图像总量约 **1056** 张，规模适中，能支撑多类别构件检测模型的训练。
*   数据集当前为初始版本，数据已整理完毕，可直接使用。
*   图像涵盖古建筑不同部位与不同光照条件下的构件样本。

## 知识普及：古建筑构件检测的技术要点

*   **构件形态多样**：从细长的脊饰到复杂的斗拱体系，构件在形态、尺度上差异显著，需模型具备多类别特征提取能力。
*   **密集与遮挡**：斗拱等构件密集排列，相互遮挡常见，需采用多尺度特征融合与 NMS 参数调优策略。
*   **材质与纹理干扰**：古建筑构件材质（木材、砖瓦、彩绘）纹理复杂，可能与构件混淆，模型需依赖纹理与颜色特征进行区分。
*   **光照与视角影响**：古建筑多为户外拍摄，光照变化大，且拍摄角度多样，建议训练时加入亮度、对比度增强与视角变换。
*   **应用闭环**：检测结果可导入古建筑 BIM 系统，用于构件编目、状态评估与修缮规划，服务于建筑遗产的数字化保护。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例（类别名称需替换为您实际使用的中文名称）：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 19
names: ['占位类别一', '占位类别二', '博风板', '垂脊', '数据库构建', '斗拱', 
        '斗拱补间铺作', '斗拱转角铺作', '斗拱柱头铺作', '飞檐', '梁架', 
        '牛腿', '戗脊', '驼峰', '悬鱼', '月梁', '正脊', '柱础', '柱子']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
